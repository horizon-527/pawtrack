# 实施计划与默认决策

## 产品边界
已实现用户各自设备隔离、多设备绑定与切换、最近位置、按日期轨迹、在线/定位过期状态、寻找模式请求/确认。结构阶段先人持设备验证，宠物佩戴须根据实物尺寸和重量再验。
“实时”目标为网络和定位正常时寻找模式10秒、普通模式60秒；小程序位置约5秒刷新、轨迹约30秒自动刷新，手动刷新即时请求。实际设备网络调用会阻塞，尚未通过实机测量。当前没有静止300秒、运动计步/健康分析、电子围栏/推送、精准电量计、休眠续航或量产外壳的实现。

## 架构
GNSS WGS84 坐标 → 4G HTTPS 上报 → 服务存储 → 授权 API → 小程序 GCJ02 地图。
正式代码采用FastAPI+SQLite、单实例单worker部署；早期标准库版本只用于本机原型。小程序采用微信原生，不额外引入跨端框架。

## 阶段验收
1. 软件闭环（已建立原型）：模拟上报、读取最新位置、24 小时轨迹；重启服务不丢数据；拒绝无授权请求。
2. 硬件桌面验证：运营商联网、户外 GNSS、真实坐标回传；连续两小时，记录有效点比例和上传延迟。
3. 故障验证：断网缓存与恢复、重复消息去重、无定位状态、断电重启、旧数据提示；后补点不覆盖新位置。
4. 微信联调：测试 AppID、GCJ02 转换与地标对照、微信登录、绑定码、每个用户只能访问自己的设备、HTTPS 合法域名、真机地图。
5. 结构和功耗：测量各模式平均/峰值电流、24 小时耗电、发热、重量、固定可靠性。先人携带，合格后短时监督试戴；未验证前不宣称防水，不在佩戴时充电。
6. 最终验收：设备脱离主人手机和 Wi-Fi 独立上传，小程序收到真实位置与轨迹；现场测延迟和断网行为。

首轮原型预算上限暂定 1500 元，不是已核验报价；先购一套测试硬件，不批量采购。小型化和订阅费用单独核算。软件原型已开始；剩余排期以硬件到货、微信账号与实测结果为依据，不承诺固定交付日。

## 开源评估
Traccar：https://github.com/traccar/traccar （Apache-2.0），支持多种定位协议。若采购可配置服务器地址的成品追踪器，先核对协议再考虑使用。当前未集成、未复制其代码；自研板先走明确的 HTTPS JSON 协议，避免同时引入大型平台。
微信原生文档：https://developers.weixin.qq.com/miniprogram/dev/component/map.html
地图上线前重点验证 GCJ02 坐标；当前官方文档抓取未成功，开发者工具和真机验收仍必需。
