# 正式上线门槛
当前本地服务不能直接用于生产。
- 微信小程序 AppID 与主体账号、当前类目/审核要求、隐私说明及位置数据处理范围核验。
- 服务域名、HTTPS、合法域名配置；国内部署按服务商与当前要求办理必要手续。
- 服务端验证 wx.login code，AppSecret 仅服务端保存；用户设备归属校验。
- 一次性绑定码、设备独立密钥、令牌轮换、限流、审计；不把设备密钥放入小程序。
- 采用生产 Web 服务与反向代理，备份、恢复测试、定位数据保留和删除策略。
- 已接入 WGS84 → GCJ02 近似转换，仍需真实地标对照；不得直接画未经转换的 GNSS 坐标。
- 真机验证前后台刷新、断网提示、定位过期、轨迹缺口、24 小时边界。
- 实体硬件安全、续航、固定、充电与佩戴测试。
