# 上线门槛
[真实测试步骤、指标与记录模板](acceptance.md)；[从采购到上线的操作指南](getting-started.md)。

已准备：用户会话验证、设备归属、独立设备密钥、一次性绑定码、HTTPS网关配置、备份恢复工具、账户与轨迹删除、限流与保留期。以下全部验收后才可称为正式上线：

- [ ] 微信真实AppID和主体、当前服务类目/审核要求、运营主体和联系方式。
- [ ] 真实微信code交换、令牌过期、真机登录与绑定。
- [ ] 部署服务器/域名、证书签发、微信request合法域名；国内部署按当前服务商要求办理必要手续。
- [ ] Docker容器启动与重启、持久卷权限、健康检查、备份计划、恢复演练。
- [ ] 生产config.js不含开发令牌，正确使用v1会话；urlCheck开启。
- [ ] 原始WGS84与地图坐标经过真实地标对照。
- [ ] 实体设备脱离手机/Wi-Fi独立上传；断网、重启、缓存满、无定位、密钥撤销测试。
- [ ] 实体模块正确证书成功、错误CA/过期/错误域名失败；验证不通过时改用PPP+ESP-TLS。
- [ ] 实测寻找模式延迟和24小时耗电，选择匹配电池与保护/充电方案。
- [ ] 外壳、固定、防水、发热与佩戴验收。未测不宣称防水或续航。
- [ ] 隐私说明补齐运营信息；确认数据保留/删除和备份清理生效。
