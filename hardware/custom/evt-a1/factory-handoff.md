## 制造之前必须关闭的事项

1. **模组引脚资料矛盾**：合宙硬件手册 V2.2 将 PIN2/PIN103 列入悬空列表，最新 20260914 参考原理图却明确 PIN2=GNSS_ANT、PIN103=GND。本版按最新参考原理图接线。须由合宙或具有该模组设计经验的方案商确认适用于实际采购的 Air780EGH，并给书面结论；不确认就停止投板，不拿相似型号替代。
2. 核对整个原理图和 BOM，特别是 RNM0015A 的不规则 15 脚封装、BQ24074 17 号散热焊盘、模块 109 个焊盘方向、USB-C、SIM 和 NMOS 引脚。KiCad 的 U.FL 封装 **1=信号，2=两处地**，与厂商参考图使用的连接器编号不同，不能照抄参考图编号。
3. 核对 TPS63070 电感和电容有效容量、环路及热设计；确认 USB 输入限流 500mA、目标充电约 350mA 时的电池补充模式，评估 3.8V/2A 负载阶跃。只能按芯片资料证明设计约束，不能用 ERC/DRC 代替负载实测。
4. 确认实际四层叠层、RF 50Ω 阻抗、USB D+/D− 90Ω 差分阻抗及耦合/长度、铜厚、过孔工艺、阻焊和钢网开口，重新检查所有制造文件。RF 走线使用首轮 0.20mm 工程宽度；它不是已有工厂叠层的阻抗认证结果。USB 当前为连通性布线，尚未完成阻抗/差分对认证，应按所选叠层由方案商收敛并改版，确认下载和数据传输稳定后交付。
5. 电池、天线、密钥烧录及装配方案明确后，更新最终 BOM 并签署本次样机制造版本。禁止不通知替换模组、充电芯片、稳压芯片、电感或电池。

## PCB 与贴片要求

目标四层、64×46mm、厚 1.0mm、外层铜 35µm，圆角外壳适配的四个 M2 孔。F.Cu 元件及 RF/信号，In1 连续地参考，In2 3.8V 电源分配，B.Cu SIM、信号及局部 BAT/SYS 配电。板面电源铺铜和过孔要共同承担峰值电流；细走线仅作焊盘颈部或控制信号，检查最终图纸中实际电流路径。

厂商先提供可生产叠层。规划 F.Cu 到 In1 介质约 0.11mm、介电常数约 4.2；零铜厚微带估算只能作初值。用实际材料、铜厚及阻焊重算 **50Ω±10%** 并提供阻抗测试条/记录；需要改线宽就更新 PCB 和 Gerber 后重跑 DRC。不得割断 RF 下方 In1 地平面，不在馈线下方开电源槽。

以实际制造文件最小孔径与过孔表确认工艺。涉及 SMD 焊盘内过孔的电源/地连接，必须树脂塞孔并电镀盖帽（VIPPO），禁止开放孔直接吸走焊锡；如不能提供该工艺，须工程师重新扇出和重验 DRC，不能仅取消过孔。钢网、热焊盘分窗、锡量及 X-ray 检查由工艺工程师确认。模块和 QFN 不接受只看外观的焊接验收。

`bom.csv` 中 `Populate=0` 不采购/不贴。C16–C19 为射频调谐预留，TP/H 是 PCB 特征，不能当元器件贴装。贴片机角度不同于 KiCad 坐标约定时，须校正首件方向；不要把导出的角度直接当机器旋转角。核对 U1 PIN1、U2/U3 PIN1、Q1、C14 极性、SIM 卡盖开口方向。

`placements.csv` 使用毫米、板设计绝对原点：X 向右、Y 向上，因此本板 PosY 为负数；bottom 未使用负 X 镜像，J5 的导出角度为180°。厂商以原生 PCB 校正机器坐标，不要再次凭经验镜像。制造层包括4铜、2阻焊、2丝印、2钢网及板框；PTH/NPTH 分开，4个2.2mm板固定孔为NPTH，槽孔保留在PTH钻孔文件。

## 充电策略与首次上电

BQ24074 的硬件 NTC 监控用于独立后备保护，其手册标称约 0–50°C（指定曲线），不是本项目电池充电合格范围的实测成绩。GPIO27 → NMOS → CE 控制电路默认禁充，5V CE 不直接进入模组 GPIO。固件仅在温度估计有效、位于 **5–40°C** 且温度验收标志已开启时允许充电。TS 增加高阻采样并考虑其负载；由电池厂提供实际曲线，必须实测校准，使关键温区误差≤2°C，再对照电池允许范围收紧阈值。

正常关机、重启、未烧程序、ADC 无效、NTC 断路/短路时，充电必须关闭。硬件 TS 保护独立做故障注入；程序能开启充电不证明后备保护合格。NTC 不允许用固定电阻长期替代。

首次上电由方案商做：先外接限流电源验证无短路，短接 TP8(REG_EN) 到地禁止稳压器/模组运行，检查 USB→充电器 SYS 路径和温控电平；再以受控 BAT 电源约3.8V供电、设置适当限流，解除 TP8，验证 MODEM 3.8V。随后接入已核对极性的保护电池，才能做实际 4G 发射测试。USB 固定 500mA 输入不足以独自覆盖4G峰值，不能以“插 USB 能亮灯”作为联网稳定验收。

任何测试注入用隔离夹具、电池模拟器、电子负载或合格测试仪；不靠真实锂电池硬短路制造故障。充电时从宠物身上取下，只在人监督、符合电池温度要求时测试。

## 烧录与软件联调

使用合宙 Luatools 和适用于 **Air780EGH** 的官方底层固件，先记录版本及 SHA256。应用文件为 `firmware/main.lua`、`protocol.lua`、`queue.lua`、`vendor/exgnss.lua`，在 Luatools 文件列表中保证 `require('exgnss')` 可找到。每台单独生成 `config.lua`，烧入 API 域名、设备令牌及 CA PEM；这些文件不得上传 GitHub 或放进公共交付包。

按合宙说明使用 VDD_EXT 与 USB_BOOT 测试触点进入下载模式，USB 数据线连接，电池/台架供电保证峰值。PWRKEY 按厂商要求操作，RESET 不当作拔电池；不把 DBG 串口当 ESP32 串口。设备在后台登记、生成绑定码后，微信小程序绑定并观察真实位置。

TLS 和充电验收标志默认关闭。只有 exact 底层固件版本的正确 CA/错误 CA/过期证书/错误主机名四组实测通过，才在该设备配置中设置 `tls_qualified=true`；只通过电脑 TLS 测试不够。只有温度/充电/ADC 校准测试通过，才设置 `charge_qualified=true`。这是工程交付验收条件，不能为了“跑起来”删除开关和认证参数。

冷启动、复位会保存启动编号，队列64点满时停止采新点并记录计数，保留已有点重传；最长缓存跨度取决于采样间隔，不能承诺无限补传。fskv 清空后应换新设备密钥/注册记录，避免重新使用旧 bootId。电池 SOC 本版未校准，心跳和位置不编造电量百分比。
