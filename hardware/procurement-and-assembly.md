## 下单顺序

1. **先向微雪官方渠道确认开发板套装**：完整型号、V2.0版本、GNSS实装、配套天线、USB供电及GPIO资料；确认后买1套。
2. **带模组型号到营业厅办理SIM**：本轮优先联通，实际覆盖与兼容性先核对。若普通实名SIM不允许用于数据模组，向运营商正式渠道咨询可供单设备试用的物联网卡，不自行假定套餐可用。实名要求、月费、流量结转和APN以办理时的说明为准。
3. **补齐电源、线和工具**：核对套装附件后再买；同类现有工具符合规格即可复用。
4. **开发板到货后才买盒子**：根据板、天线接头和线缆弯折空间测尺寸。先做桌面/人持盒，电池及宠物佩戴外壳等实测功耗与重量后采购。

SIM不从不明充值平台购买超低价“无限流量卡”。办理时问清实名、续费、机卡绑定、跨设备限制及流量查询方式；不要把卖家默认APN直接当成你这张卡的参数。首轮不买裸锂电池、定制PCB、摄像头、太阳能板或批量项圈外壳。

## 到货检查

断电拍照，记录型号、PCB 版本、模组型号、天线接口丝印、SIM 卡座尺寸、USB 口/开关、电池座极性。把包装说明和订单保存。若到的是 A7670E、裸 SIM7670G、无 GNSS 的版本或与资料不符，暂停接线并换正确型号；现有固件不能假定其他型号等价。

厂商概览说明同一个 Type-C 接口可通过开关路由至 ESP/模组；[官方 ESP-IDF 示例](https://docs.waveshare.net/ESP32-S3-SIM7670G-4G/ESP-IDF)使用板上 CH343 进行烧录。不要把 ESP 的日志串口当作 SIM 的 AT 串口。

## 桌面组装顺序

1. 拔掉 USB 和电池，关闭模块电源。按实际卡槽说明插入已激活 SIM；不裁剪不匹配的 SIM。
2. 对照丝印，分别连接 LTE 和 GNSS 天线。接头垂直对齐再轻压，用胶带/固定件给线缆卸力。
3. 板固定在绝缘螺丝柱上，关闭不用的摄像头。连接厂商支持的稳定 USB 供电；本阶段不用散装电池。
4. 根据当前版本说明切到 ESP UART 烧录模式，电脑识别 CH343。Mac 若没有串口，按 [厂商 FAQ](https://docs.waveshare.net/ESP32-S3-SIM7670G-4G/FAQ)安装匹配串口驱动，使用厂家来源。
5. 切到模组 USB 直连模式，找到模组 AT 口；ESP 固件/串口监视器停止占用。先验证模组，再导入根 CA。
6. 导入 CA 后断电，切回正常 ESP ↔ 模组串口通信路由并启用 4G 电源，再烧录自己的固件。开关名/位置按实物确认，不根据另一型号图片猜。
7. 使用日志看到运行状态；GNSS 天线放开阔室外，先等待真实定位。服务器和小程序应出现该设备的新点。

没有必要给集成板额外焊接 RX/TX。当前固件默认 ESP RX=GPIO17、TX=GPIO18、115200；到货版本不同就先核对原理图，在 menuconfig 改配置。

## 最小 AT 自检

用串口软件连接模组 AT 口，115200，指令以 CRLF 结束。以下操作不需要把设备密钥写进串口测试窗口：

| 指令 | 期望 | 不符时处理 |
|---|---|---|
| `AT` | OK | 检查 4G 电源、AT 口、USB 路由和波特率 |
| `ATI` / `AT+CGMR` | 模组型号/固件版本 | 保存版本以便排查，不混用其他系列资料 |
| `AT+CPIN?` | READY | 卡激活、卡座接触；需要 PIN 时按运营商流程处理 |
| `AT+CEREG?` | 归属/漫游已注册状态 | 查套餐、频段和信号；漫游须套餐允许 |
| `AT+CSQ` | 有可用信号；99 为未知 | 换室外位置、检查 LTE 天线，不据此推算定位精度 |
| `AT+CGNSSPWR=1` | GNSS 启动/OK | 检查该版本 GNSS 支持与指令返回 |
| `AT+CGPSINFO` | 有坐标、日期和 UTC 时间 | 开阔室外等待；空字段是未定位 |

不要在公开截图中展示 IMSI、ICCID、deviceToken 或真实坐标。厂家描述室外定位常需约一分钟，仅作为参考，不是本产品已实测成绩。[官方连接与 GNSS 说明](https://docs.waveshare.net/ESP32-S3-SIM7670G-4G/Windows)

## 根 CA 和 TLS

服务网关已固定 Let's Encrypt 签发；从 [Let's Encrypt 官方证书目录](https://letsencrypt.org/certificates/)获取与**你的当前服务证书链**对应的自签根 CA PEM。不要抓服务器叶证书当根，不用过期交叉链。初始可核对 ISRG Root X1；实际链不同就按验证结果准备正确根。

电脑先用该 PEM 检查：

```sh
work/venv/bin/python tools/doctor.py --base https://你的API域名 --ca secrets/pawtrack-ca.pem
work/venv/bin/pip install -r requirements-hardware.txt
work/venv/bin/python tools/install_modem_ca.py \
  --port 实际模组AT串口 --certificate secrets/pawtrack-ca.pem
```

它导入文件名 `pawtrack-ca.pem`，应与固件 menuconfig 相同。示例 `--port` 必须替换成当前串口，Mac 可用 `python -m serial.tools.list_ports` 查看；插拔对比识别，不选择电脑上其他设备。

固件开启服务器证书认证、SNI 和时间验证。模组主机名验证行为仍须实物做错误域名测试；电脑验证通过不能代替它。严格按 [验收表](../docs/acceptance.md) 完成正确 CA、错误 CA、过期、错误主机名四组测试。

## 电池与外壳：在测量之后采购

当前板可能带 18650 电池座，按实物版本确认。首次电池启用和保护机制见 [厂商 FAQ](https://docs.waveshare.net/ESP32-S3-SIM7670G-4G/FAQ)。不凭接口外观决定电池极性，不把未知裸电池直接接 GPIO。

先记录普通/寻找模式各 24 小时的 USB 侧 Wh 和最大电流，设备总重量、盒体尺寸、发热、SIM 用量。目标电池储能预算可取 `实测24小时Wh / 0.8 × 1.3` 作为保守初算（0.8 是规划转换效率、1.3 是裕量，均需实测替换）。3.7V 电池容量约为 `Wh / 3.7 × 1000 mAh`。USB 测量不能直接当电池侧精确续航。

此开发板 + 18650 套装可能过重，尤其不适合小体型宠物。佩戴版本需要根据测量改为小型 PCB/保护电池/外壳或经过验证的硬件模块；当前没有提供已验证的量产 PCB、精确电量计、低功耗休眠或防水结构。无法在没有实体尺寸、电流与宠物适配数据时保证安全合适。

外壳委托制作时给出：实物三维尺寸、整体质量、板固定孔位、天线无遮挡方向、螺丝柱、电池隔离/保护、充电口盖、密封圈、线缆卸力、圆滑边缘、双点固定、充电时取下的要求。先做等重空壳适配，再做通电人持测试；首次佩戴由人监督，猫需考虑脱扣项圈适配，不依赖未验证的定位器单独放养。
